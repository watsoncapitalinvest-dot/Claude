IF IT CRASHES - what to send back
=================================

Send these two things and we can usually say exactly what broke.


1. THE LOG

   Documents\OpenXcom\openxcom.log

   It is appended to, never wiped, so relaunching after a crash does NOT
   destroy it. You can keep playing and send it later.

   Near the bottom of a crash you will see lines marked [FATAL] followed by
   a stack trace.


2. THE CRASH DUMP

   Documents\OpenXcom\<date-and-time>.dmp

   One is written every time the game crashes, named for when it happened.
   Send the one whose timestamp matches the crash.


ALSO USEFUL, IF YOU CAN

   The save you were playing, from Documents\OpenXcom\xcom1\
   A sentence on what you were doing - geoscape or a battle, which mission,
   what you had just clicked.


WHY THE .pdb SITS NEXT TO THE EXE

   OpenXcom.pdb ships beside OpenXcom.exe and must stay there. It is the
   symbol file. With it, the crash trace names the functions that failed;
   without it every line is a raw address like OpenXcom.exe+0x39e817, which
   tells us nothing.

   It only matches the exe it was built with. If you update the exe, take
   the new .pdb with it - an old one resolves nothing and is worse than
   none, because it can produce names that are confidently wrong.


WHAT ELSE IS IN THE LOG

   Cobra's economy writes to the log as it runs, about twenty to thirty
   lines a month - what each region holds, which benches took up which
   research, what a raid cost Cobra. Those lines are on by default on
   purpose: they used to be behind an environment variable, which meant any
   crash report arrived with no trace of what Cobra had been doing.

   Lines to look for:

     [econ] STR_NORTH_AMERICA materiel=80/50  funds=752/480
     [econ] a bench at STR_COBRA_RESEARCH_LAB#1 took up STR_COBRA_RIFLES
     [econ] the raid cost Cobra 30/90 on STR_COBRA_LASERS

   If you want a quiet log, set OXCE_ECON_QUIET=1 before launching.


IF THE GAME HANGS INSTEAD OF CRASHING

   No .dmp is written for a hang - nothing crashed. Send the log and say
   roughly when it froze and what was on screen. A hang with the geoscape
   running is a different problem from one during a battle, and the last
   few log lines usually separate the two.
