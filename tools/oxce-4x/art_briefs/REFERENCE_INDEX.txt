CHARACTER AND WEAPON REFERENCE - WHERE IT ALL IS

Reference lives on John's machine, not in this repository. He set this folder as
the shared one on 11 Nov; design chat and build chat both read from it:

    C:\GI-Joe-Silent-Storm\GIJoe_XCOM_4x\Reference\

    _READ_ME_FIRST.md         his own index of the folder - read it first
    design\                   XCOM_HANDOFF.md (the build brief), the catalog,
                              STORY_BRIEF, COBRA_TECH_BRIEF
    facilities\               all 109 base rooms as finished isometric art, the
                              index, 4 contact sheets, the 142-item library
    lists\                    the weapon spreadsheets - see below
    weapon_list\              WEAPON_LIST.csv: what each figure came with
    yearbook_carded_figures\  362 carded-figure photos, NAMED BY CHARACTER
    rolodex_file_cards\       975 file-card scans, numeric names, NOT labelled
    terrain_pack\             community terrain - reference only, NEVER ship

His rules for all of it, copied here so they travel with the index: scraped
photos and the terrain pack are private reference and are never shipped in the
game, and nothing published carries Hasbro logos or branding. None of it is
copied into this repository, which is public. Only this index is committed.

THE WEAPON LISTS SETTLE AN OPEN QUESTION IN GUN_ROSTER.md

That file has nineteen weapons marked "Canon (well known); filecard not yet
checked". lists\ answers it with dated sources:

    Weapon_Reference_List.xlsx    50 real guns + 26 attachments, every one 1998
                                  or earlier, with a suggested side and the
                                  era-appropriate attachments for each
    Joe_Weapons_Real_Basis.xlsx   101 toy guns mapped to the real gun each copies.
                                  Only 27 FIRST APPEARED IN 1982-1998, the era
                                  this game uses; the other 74 are from 2002+
                                  lines and are outside the catalog cutoff.
    Joe_Figure_Weapons_and_Gear.xlsx   every figure's weapons and gear
