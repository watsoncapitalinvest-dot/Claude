ROOM OBJECTS - WHAT GOES IN EACH FACILITY
G.I. Joe XCOM. Objects are drawn as SEPARATE pictures and laid onto the empty room shells.
Private project art.

=== RULES FOR EVERY OBJECT (paste at the top of each request) ===
- Seen from DIRECTLY ABOVE, like the room shells: top of the object only, no side view, no angle.
- Same light as the shells: from the upper left, matte, no glare.
- Flat #FF00FF magenta background, hard edges, one object per file.
- Size: draw at the pixel size given (a room square is 192 x 192 px). Sizes are footprints seen from above.
- No text, numbers, logos, emblems or insignia (no Cobra symbol, no Joe logo). No people.
- Rooms double as battle maps, so solid objects (consoles, crates, machines) are things a soldier
  can hide behind; keep them clearly solid with clear edges.
- Joe objects: olive drab, grey steel, wood. Cobra objects: dark steel, deep blue, red accents.
- File name: obj_<room>_<object>.png, or obj_common_<object>.png for the shared kit.

=== ORDER ===
1. Common kit (reused in many rooms) - do these first.
2. The Pit start rooms (marked "start").
3. The rest of the Pit, then outposts.
4. Cobra installations last.
