ROOM OBJECTS - FOUR ORDERS
==========================

Send one group at a time, in order. Each folder is complete on its own: the
order (every object with its file name and exact canvas size) and the scale
guide. Group 1 must be done before 2, 3 and 4, because they reuse its kit.

  group_1   OBJECTS_GROUP_1.txt    57 objects   common kit, construction kit, the Pit's start rooms
  group_2   OBJECTS_GROUP_2.txt   134 objects   the rest of the Pit, Joe department heads
  group_3   OBJECTS_GROUP_3.txt    38 objects   Joe outposts: naval, outdoor, space
  group_4   OBJECTS_GROUP_4.txt   123 objects   Cobra: Cobra kit, Cobra rooms, Cobra heads

352 objects in all. ROOM_OBJECTS_LIST_source.txt is the requisition they were
built from.
