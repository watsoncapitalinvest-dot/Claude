G.I. JOE APC — 1980s CARTOON ART

11 separate full-resolution PNG illustrations with actual transparent alpha:
front, rear, left and right profiles; all four front/rear three-quarter views;
raised right-front view; overhead; and open top-down interior.

Painted from the user-supplied APC photographs, with blueprint and decal sheet
as supporting references. Olive hull, black tires, tan/ochre canvas camouflage,
dark windows, original stars and red-white-blue side markings. The source photos
and project files were not modified. View filenames match the original references.

PREVIEW.jpg is a labeled overview, with each thumbnail enlarged independently.
VIEW_LIST.csv records the original image dimensions. PNG pixels are preserved
as generated; no resizing or recoloring has been applied to the delivered PNGs.

These are separate 2D style adaptations, not rotations rendered from one 3D
model. No sprite-frame alignment or game import was performed. Use the supplied
photos for final geometry/marking checks; tiny generated decal text can vary.

The optional loose-parts illustration was rejected twice by the image tool's
automatic safety filter. It is not included. All requested vehicle angles and
the open interior are included.
